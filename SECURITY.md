# Security policy

seqcounter is a command line tool that runs locally on your own data; it has no server component.
If you find a security problem (for example, a crafted input file that makes it write outside the output folder or
run unexpected commands), please **do not open a public issue**. Report it privately instead, either through
[GitHub's private vulnerability reporting](https://github.com/duceppemo/seqcounter/security/advisories/new)
or by email to marc-olivier.duceppe@inspection.gc.ca.

Only the latest release receives fixes.
